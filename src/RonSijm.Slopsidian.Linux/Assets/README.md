# Native assets

`tux-notebook.png` is the generated Linux mascot, revised at Jeffrey’s request
including the corrected lower-right foot. Its exact prompts, edit history and
hashes are retained in `tux-notebook.provenance.json` and PNG metadata.
`tools/linux/slopsidian-linux.png` is the corresponding desktop-menu asset.

`icons.svg` and `icons-LICENSE.txt` were retained byte-for-byte from the upstream
Slopsidian webhost assets when that host was removed from this Linux fork.
Original project: https://github.com/RonSijm/RonSijm.Slopsidian
Upstream baseline: `99a7f94746074048a0e1437dd589f1b423f4d950`.
The icon license remains alongside the sprite and is included in the package.
